**Title:** Put the Unity Companion License text in the repository

**Body:**

`LICENSE.md` at `de668bf` is five lines. It does not contain the grant:

```
Unity Agent Plugin © 2026 Unity Technologies

Licensed under the Unity Companion License for Unity-dependent projects (see https://unity3d.com/legal/licenses/unity_companion_license).

Unless expressly provided otherwise, the Software under this license is made available strictly on an "AS IS" BASIS WITHOUT WARRANTY OF ANY KIND, EXPRESS OR IMPLIED. Please review the license for details on these and other terms and conditions.
```

`.claude-plugin/plugin.json` line 10 says `"license": "LicenseRef-Unity-Companion-License"`. The GitHub API reports `NOASSERTION` for this repository (`gh api repos/Unity-Technologies/unity-agent-plugin/license` returns `spdx_id: NOASSERTION`, `path: LICENSE.md`), because that file is not a recognized license text.

The page the file links, read on 2026-10-04, is Unity Companion License v1.4. Section 1 allows reproducing and distributing the work only in connection with content authored under a valid Unity engine license, and says no other exercise is permitted. Section 7 says the license may be updated and that later use follows the updated text. A commit pin cannot freeze terms that live only at that URL.

Catalogs that record the license of a pinned commit have nothing stable to point at, and cannot tell whether offering the plugin to arbitrary users of a coding agent is inside the grant.

Suggested fix: commit the Companion License text (the version you mean, with its date) into `LICENSE.md`, and add one sentence if you intend third-party catalogs to install this repository: that installing the plugin so someone can author Unity content under an engine license is companion use, or whatever narrower grant you actually want. This note does not choose those terms.
