**Title:** fix(ledger-design): make the agent's event schema accept inserts

**Body:**

The `ledger-architect` agent's event-sourced schema cannot record a single event. `plugins/ledger-design/agents/ledger-architect.md` line 41 declares

```sql
CONSTRAINT events_immutable CHECK (false) NO INHERIT  -- enforce no UPDATEs via trigger
```

A check constraint runs on every insert as well as every update, so `CHECK (false)` rejects every row. Reproduced on PostgreSQL 17.11 with the block at lines 32 to 42:

```text
ERROR:  new row for relation "ledger_events" violates check constraint "events_immutable"
```

Two smaller cracks sit in the same block:

- K-05: `check_event_balanced()` (line 54) is defined but never attached, while line 69 says an unbalanced event rolls the transaction back. The `/ledger` command attaches it correctly as a `DEFERRABLE INITIALLY DEFERRED` constraint trigger (`commands/ledger.md` lines 169 to 172).
- K-06: the plugin states "integer minor units always" (README.md line 37, agent line 22, command line 248), while the skill's schema and the command's Core Schema use `NUMERIC(38, 10)` amounts in major units (`skills/ledger-design/SKILL.md` line 248, `commands/ledger.md` line 332). Both are exact; the contradiction is in the rule, not the math.

Changes:

1. Replace the `CHECK (false)` line with a trigger that raises on `UPDATE` or `DELETE`:

   ```sql
   CREATE OR REPLACE FUNCTION forbid_change() RETURNS TRIGGER AS $$
   BEGIN RAISE EXCEPTION 'ledger rows are immutable'; END;
   $$ LANGUAGE plpgsql;
   CREATE TRIGGER trg_events_immutable BEFORE UPDATE OR DELETE ON ledger_events
   FOR EACH ROW EXECUTE FUNCTION forbid_change();
   ```

2. Attach `check_event_balanced()` the way the command does, as a deferred constraint trigger on `ledger_entries`.
3. State one rule for amounts: integer minor units for single-currency ledgers, and name `NUMERIC(38, 10)` as the option for multi-currency books with fractional FX amounts, in the README, the agent and the skill.

Verified on PostgreSQL 17.11 with the command's schema (`commands/ledger.md` lines 112 to 172) plus the trigger in step 1: a balanced event commits, an unbalanced event fails at commit with `Event 2 is not balanced for currency USD (net: 10000)`, and an `UPDATE` on `ledger_events` fails with `ledger rows are immutable`.
