**Title:** docs: name Startpage in the keyless-floor privacy note

**Body:**

`keyless_search` tries DuckDuckGo, then falls back to Startpage when DuckDuckGo returns nothing, then to a configured SearXNG (`web_search_keyless.py` lines 104 to 115). The privacy note in CONFIGURATION.md (line 458) says the floor "sends the query (to DuckDuckGo / your SearXNG instance) and any fetched URL (to Jina Reader)". Startpage appears in the CHANGELOG entry that added it (line 307) but not in the privacy note, the README or SKILL.md, and `web_fetch_keyless.py` (Jina Reader) is imported only by its test, so the note names a recipient the engine does not call and omits one it does.

With the HTTP layer stubbed so nothing left the machine, `grounding.web_search` with no native-search flag requested `https://html.duckduckgo.com/html/` and then `https://www.startpage.com/sp/search`; with `LAST30DAYS_NATIVE_SEARCH=1` it requested nothing.

Suggested change to CONFIGURATION.md line 448 and line 458:

```diff
-4. **Keyless engine floor** - zero-key web search (DuckDuckGo, plus an optional SearXNG instance) and zero-key page fetch (Jina Reader). Runs only when the agent session has **no** host web search **and** no paid key is set, so headless/cron and hosts without a search tool still get general-web coverage. Force it explicitly with `--web-backend=keyless`.
+4. **Keyless engine floor** - zero-key web search (DuckDuckGo, then Startpage when DuckDuckGo returns nothing, plus an optional SearXNG instance). Runs only when the agent session has **no** host web search **and** no paid key is set, so headless/cron and hosts without a search tool still get general-web coverage. Force it explicitly with `--web-backend=keyless`.
-Privacy note: the keyless floor sends the query (to DuckDuckGo / your SearXNG instance) and any fetched URL (to Jina Reader) to those third parties. It is intended for public-research use; results may be cached snapshots. It never runs when native search or a paid backend is in play.
+Privacy note: the keyless floor sends the query to DuckDuckGo, to Startpage when DuckDuckGo returns nothing, and to your SearXNG instance if one is set. It is intended for public-research use; results may be cached snapshots. It never runs when native search or a paid backend is in play.
```

If Jina Reader is meant to come back as a fetch tier, the note can keep it once the engine calls it.
