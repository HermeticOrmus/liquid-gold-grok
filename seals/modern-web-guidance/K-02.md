**Title:** README: "no network calls" and "completely private and local" contradict the Telemetry section; the Grok marketplace file cannot be installed

**Body:**

Two small things found while checking v0.0.191 in Grok Build 1.0.44.

1. **Privacy copy.** README line 368 says search runs "no network calls, no API keys", and line 372 says the CLI "works offline, completely private and local". The Telemetry & Privacy section (line 504 to 514) says, correctly, that search queries generated by the agent, guide retrieval IDs and install counts are sent to Google unless `DISABLE_TELEMETRY=1` is set, and the CLI's watchdog posts them to `play.googleapis.com/log`. The disclosure is good; the two earlier lines read as if there were none. Suggested wording for line 372: "The search runs locally with no API keys. Anonymous usage telemetry is on by default; see Telemetry & Privacy to opt out."

2. **`.grok-plugin/marketplace.json`** (added in #1272) lists the repository root as its plugin (`"source": "./"`). Grok Build does not install a marketplace's own root: after `grok plugin marketplace add` on this repository, `grok plugin install modern-web-guidance@<marketplace>` answers `No marketplace plugin named "modern-web-guidance"`. The README's Grok section already gives the install that works (`grok plugin install https://github.com/GoogleChrome/modern-web-guidance --trust`), so the marketplace file can be dropped, or the README can say not to use it.
