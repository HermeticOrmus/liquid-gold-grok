**Title:** Privacy section: mention that the bundled MCP server connects to app.axiorank.com without a key

**Body:**

The Privacy section (README line 76) says: "Nothing leaves your machine unless you set `AXIORANK_API_KEY`."

The plugin's `.mcp.json` registers the hosted server `https://app.axiorank.com/api/mcp-server/mcp`, and the README's MCP section (line 47) says public discovery works with no key. Grok attaches a trusted plugin's `.mcp.json` servers to every session (Grok plugins guide, line 154), so a Grok session with the plugin installed connects to AxioRank whether or not a key is set. No tool data is sent unless the agent calls a tool, but the connection itself does leave the machine.

Suggested fix: add one sentence to the Privacy section naming the MCP connection and how to turn it off (`grok mcp disable axiorank`), or leave the server out of `.mcp.json` until a key is configured.
