**Title:** pr-review-toolkit: README says MIT but the plugin's LICENSE is Apache-2.0

**Body:**

At `ab024cd`, `plugins/pr-review-toolkit/README.md` ends its License section with "MIT" (line 305). The license file in the same folder, `plugins/pr-review-toolkit/LICENSE`, is the Apache License 2.0, as is the repository's root `LICENSE`. A reader who checks the README gets the wrong license.

Two smaller README lines in the same file:

- The Contributing section (line 299 to 301) says the agents are maintained in `~/.claude/agents/` and in `.claude/agents/` in `claude-cli-internal`, which is not a repository readers can open. Pointing contributors at `plugins/pr-review-toolkit/` in this repository would match where the files live.
- The Installation section (line 183 to 191) describes only Claude Code's `/plugins` menu.

Suggested fix: change line 305 to "Apache-2.0" (or link `LICENSE`), and replace the Contributing lines with a link to this folder.
