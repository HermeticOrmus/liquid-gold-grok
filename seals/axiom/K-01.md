**Title:** docs: add a Grok Build install line

**Body:**

The README's install section covers Codex, Claude Code, Cursor, Gemini CLI and `npx skills`. The only Grok mention is the link to xAI's marketplace contributing guide (README line 137). The repository does ship a Grok manifest (`.grok-plugin/plugin.json`, version 1.1.0).

Adding the repository as a marketplace does not make the plugin installable. With grok 1.0.46 in a clean Grok home:

- `grok plugin marketplace add axiomhq/skills` registers the source as `skills` (the repository name, written under `[marketplace.sources]`).
- `grok plugin install axiom@skills --trust` answers `No marketplace plugin named "axiom" in "skills"`.
- `grok plugin install axiom@axiom --trust` answers `Unknown marketplace "axiom"`.

`.claude-plugin/marketplace.json`, `.cursor-plugin/marketplace.json` and `.agents/plugins/marketplace.json` list the plugin with `"source": "./"`. There is no `.grok-plugin/marketplace.json`. Grok's own plugin guide (written into a fresh Grok home by 1.0.46, `docs/user-guide/09-plugins.md`) describes a marketplace as one folder per plugin, listed from `.grok-plugin/marketplace.json` or the `.claude-plugin/` equivalent. A plugin whose source is the marketplace's own root is not offered for install. The same message is what `modern-web-guidance` gets from a marketplace entry of `./`.

This install does work, and it lands on the commit you pass:

```bash
grok plugin install https://github.com/axiomhq/skills.git --trust
```

At `8f26649612042662c1ea8318ff27a49a7c24531f` that printed `Installed 1 plugin(s) ... axiom`, `grok plugin details axiom` showed v1.1.0, and `grok inspect --json` listed 7 skills and the MCP server at `https://mcp.axiom.co/mcp`.

Suggested Grok Build section, next to the others:

### Grok Build

    grok plugin install https://github.com/axiomhq/skills.git --trust

Restart is not required. Open `/mcps`, select `axiom` and press `i` to authorize. `grok plugin marketplace add axiomhq/skills` registers the repository but does not list an installable plugin, because this plugin lives at the repository root.
