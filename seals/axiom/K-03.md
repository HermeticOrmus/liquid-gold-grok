**Title:** axiom-sre: init pulls org memory; it is not free of network calls

**Body:**

`skills/sre/SKILL.md` line 46 tells the agent to run `scripts/init` immediately, and says that "loads config and syncs memory (fast, no network calls)". The script header says the tool report is config-only and makes no network calls (line 15). Line 287 always runs `scripts/mem-sync`. When an org directory under `~/.config/axiom-sre/memory/orgs/` is a git repo, `mem-sync` runs `git pull --ff-only` (line 24).

Two runs at that commit:

- First run, no org repo: the stand-in `git` was not called. Init created `~/.config/axiom-sre/` and stopped because no deployment was configured.
- A later run with one deployment and an org directory that contained `.git`: init printed `Syncing acme...` and the stand-in `git` recorded `pull --ff-only`.

The repository README already says SRE can sync memory to a git repository you configure (line 101). The skill sentence should say the same thing, for example: init reads config from disk, and when an org memory repo is configured it runs `git pull --ff-only` in that repo. With no org repo it does not use the network.
