**Title:** Grok Build docs: three small corrections

**Body:**

The skills-only Grok adapter from #661 works as described: with grok 1.0.44 in a clean Grok home, `grok plugin install DietrichGebert/ponytail --trust` installs it, and `grok inspect --json` lists the six skills from `ponytail` with `hooks: false` and no MCP servers. Three pieces of copy still describe something else.

1. **The enable step is not needed.** README line 271 says the plugin is off by default and asks the user to enable it in `/plugins` or `config.toml`. After the install above, `~/.grok/config.toml` already holds:

   ```toml
   [plugins]
   enabled = ["ponytail"]
   ```

   and `grok inspect` reports the plugin as `"enabled": true`. Suggested wording: "The install enables the plugin. To turn it off, use `/plugins` or remove it from `[plugins] enabled` in `~/.grok/config.toml`."

2. **`commands/` is not part of the Grok adapter.** `docs/agent-portability.md` line 13 lists `commands/` for Grok Build. The folder holds Gemini CLI `.toml` files; `grok plugin validate` counts `1 command dir(s)`, but `grok inspect` loads 0 commands from ponytail. The six slash names Grok shows come from the skills, so dropping `commands/` from that row matches what loads.

3. **The help card describes hook-host settings.** `skills/ponytail-help/SKILL.md`, which Grok loads, says the default mode is "auto-active every session" (line 46), that `PONYTAIL_DEFAULT_MODE` or `~/.config/ponytail/config.json` sets it, that `"off"` disables auto-activation on session start (line 58), and that updates go through `/plugin` (line 65). In Grok nothing reads those settings: `hooks/ponytail-config.js` (line 78) and the root `__init__.py` (line 53) do, and Grok loads neither. README line 295 says the same without naming hosts. A short line on the help card would cover it, for example: "Grok Build: ponytail loads from its skill description or `/ponytail`; `PONYTAIL_DEFAULT_MODE` and the config file do not apply. Say 'stop ponytail', or run `grok plugin disable ponytail`. Update with `grok plugin update ponytail`."
