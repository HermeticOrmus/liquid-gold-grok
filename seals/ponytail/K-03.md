**Title:** Grok marketplace: use a `url` source, Grok's scanner rejects `"./"`

**Body:**

The direct install in the Grok Build section works (`grok plugin install DietrichGebert/ponytail --trust`). The marketplace route that `.grok-plugin/marketplace.json` offers does not. With grok 1.0.44 in a clean Grok home:

```text
$ grok plugin marketplace add DietrichGebert/ponytail
Added marketplace source: ponytail (https://github.com/DietrichGebert/ponytail.git)
$ grok plugin install ponytail@ponytail --trust
Error: No marketplace plugin named "ponytail" in "ponytail".
```

With `--debug`, the scanner says why:

```text
WARN xai_grok_plugin_marketplace::scanner: marketplace index entry 'ponytail' has invalid source path: marketplace path is empty
```

The commit message of #661 (2ed6c52) already notes that Grok's scanner rejects the `"./"` root source. I tried the other source forms on a local copy of the repo at e3ba2aa, added with `grok plugin marketplace add <path>`:

| `source` value | Result |
|---|---|
| `"./"` | `marketplace path is empty` |
| `"."` | `marketplace path must not contain current-directory components` |
| `{"source": "github", "repo": "DietrichGebert/ponytail"}` | not listed (the xai-org/plugin-marketplace#123 case) |
| `{"source": "url", "url": "https://github.com/DietrichGebert/ponytail.git"}` | `Installed 1 plugin(s) from mk: ponytail` |

Suggested change to `.grok-plugin/marketplace.json` (line 12):

```json
"source": {
  "source": "url",
  "url": "https://github.com/DietrichGebert/ponytail.git"
}
```

A `url` source installs the default branch head, the same thing the direct install does. Compound Engineering's Grok marketplace file uses the same form: https://github.com/EveryInc/compound-engineering-plugin/blob/1fd12d69812b9c48e0b054bb4a000de2cb37f744/.grok-plugin/marketplace.json#L12

`tests/grok-plugin.test.js` could pin it with one assertion that the Grok marketplace source is an object with `"source": "url"`.
