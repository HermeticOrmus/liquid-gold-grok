**Title:** using-superpowers: add a Grok Build platform reference

**Body:**

The README documents installing Superpowers in Grok Build (`grok plugin install superpowers@xai-official --trust`, README.md line 187 at `8ca22db`), and the plugin installs and validates cleanly with grok 1.0.44.

`skills/using-superpowers/SKILL.md` has a Platform Adaptation section (line 52) that tells each harness to read its reference file, and lists Claude Code, Codex, Pi, Antigravity, Hermes Agent and Muse. Grok Build has no entry, so a Grok session gets no tool mapping for the skills that name Claude Code tools.

Suggested fix: add `skills/using-superpowers/references/grok-tools.md` with the Grok Build names for the tools the skills use, and add a `Grok Build: references/grok-tools.md` line to the list. I have not written the mapping itself, because it should come from a Grok session with the tool list in front of it rather than from guesses.
