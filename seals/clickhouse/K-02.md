**Title:** README: install lines that work on Grok Build 1.0.46

**Body:**

The README and `skills/clickhouse-best-practices/README.md` tell people to run `grok plugin install clickhouse --trust` and `grok --plugin-dir ./clickhouse-grok-plugin`. On grok 1.0.46, in a home with no marketplace registered, the first exits 1:

```
No marketplace plugin named "clickhouse" in any registered marketplace.
```

The second exits 2: `unexpected argument '--plugin-dir'`. `grok --help` has no `--plugin-dir` flag.

These two lines do install the plugin:

```bash
grok plugin install ClickHouse/clickhouse-grok-plugin --trust
grok plugin install "https://github.com/ClickHouse/clickhouse-grok-plugin.git@5aa19f15f10253b13a6f4edd0cb5e2681ec28747" --trust
```

The shorthand followed `main` and landed on `5aa19f15f10253b13a6f4edd0cb5e2681ec28747` on 2026-10-04. A local checkout installs with `grok plugin install ./clickhouse-grok-plugin --trust`.

`skills/setup/SKILL.md` line 21 says to run `/plugin`. Grok's slash-command list names `/plugins` (the extensions modal; `/marketplace` is a separate tab).

Proposed change: replace both install sections with the shorthand and the pinned URL, drop `grok --plugin-dir`, and change `/plugin` to `/plugins`.
