**Title:** setup: say how to enable the remote MCP server, and name the tools it exposes

**Body:**

Two small gaps between the plugin copy and ClickHouse's remote MCP page (https://clickhouse.com/docs/products/cloud/features/ai-ml/remote-mcp, read 2026-10-04).

1. `skills/setup/SKILL.md` steps 1 to 3 say to check that the server appears, sign in with OAuth, and run a SELECT. The page says: "The remote MCP server must be enabled per service before it can accept connections" (console: service, Connect, MCP, enable). The skill links that page and never puts the step in the list.

2. `README.md` line 25 says the server is for schema inspection and read-only SQL. The setup skill (lines 39 to 60) and the page list 13 tools, including organization and service details, backups, ClickPipes, and `get_organization_cost`. The page also says every tool is read-only.

Proposed change: add the console enable step as step 1 in `skills/setup/SKILL.md`, and extend the README sentence so it names schema, SQL, services, backups, ClickPipes and billing, still read-only.
