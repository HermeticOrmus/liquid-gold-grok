**Title:** security-guidance: README does not disclose the unpinned `pip install claude-agent-sdk`, which PostToolUse also triggers

**Body:**

The README's "Privacy and data handling" section explains what the reviews send to the model endpoint, and that the debug log is never uploaded. It does not say that the plugin downloads and installs a package from PyPI. At `ab024cd`:

- `hooks/ensure_agent_sdk.py` (line 594, and the `--target` fallback at line 433) runs `pip install claude-agent-sdk` with no version, into a venv under the plugin state dir (`~/.claude/security/` by default).
- `hooks/security_reminder_hook.py` (line 2289 to 2296) also spawns `ensure_agent_sdk.py` detached from the first `PostToolUse` event, via `_maybe_bootstrap_agent_sdk_async()`.

Reproduction, outside any agent session, with no `ANTHROPIC_API_KEY` or `ANTHROPIC_AUTH_TOKEN`, with `ENABLE_CODE_SECURITY_REVIEW=0`, and with `SECURITY_WARNINGS_STATE_DIR` pointed at an empty scratch dir: pipe one `PostToolUse` `Write` event into `bash hooks/sg-python.sh hooks/security_reminder_hook.py`. The hook prints its pattern warning and exits 0, and a detached process builds `agent-sdk-venv` in the state dir: 302 MB, 3,680 files, `claude-agent-sdk 0.2.163` and `mcp 2.2.0`.

#5331 already covers the SessionStart installer ignoring credentials and `SECURITY_GUIDANCE_DISABLE`. This issue is about the parts it does not cover:

1. **Disclosure.** Say in the README that the plugin installs `claude-agent-sdk` from PyPI on first use, where, and roughly how large it is.
2. **Pinning.** Install a specific `claude-agent-sdk` version that the plugin release was tested with, so a plugin version always means the same code.
3. **The PostToolUse trigger.** Gate `_maybe_bootstrap_agent_sdk_async()` on the same conditions #5331 proposes for SessionStart (credentials present, reviews enabled), so turning the reviews off also stops the download.

4. **Metrics.** Every hook prints a `metrics` object (`security_reminder_hook.py` line 276) that, per the comments in `ensure_agent_sdk.py` (line 67 to 80), Claude Code forwards to its plugin telemetry. One README line saying so, and whether it can be turned off, would complete the privacy section.
