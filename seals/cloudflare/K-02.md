**Title:** README: add a Grok Build install section

**Body:**

The plugin installs and works in Grok Build as it is. With grok 1.0.44 in a clean Grok home, `grok plugin install https://github.com/cloudflare/skills.git@626547c06881a20b3322bdc2ed6e6451b33a4fb6 --trust` installs `cloudflare v1.0.1`, and `grok plugin details cloudflare` reports the skills and the MCP server (`components: 1 skill dir(s), 0 command dir(s), 0 agent dir(s), MCP servers`). The plugin is also listed in xAI's official Grok marketplace.

The Installing section (README.md line 5) covers Codex, Claude Code, VS Code, Cursor, `npx skills` and a manual copy, but not Grok Build, and the turnstile-spin README (line 29) links the skill only into `~/.claude/skills`.

Suggested fix: a short section after Claude Code:

```sh
grok plugin install cloudflare@xai-official --trust
```

or, without the xAI marketplace registered, the direct form `grok plugin install cloudflare/skills --trust` (checked in a clean Grok home: `Installed 1 plugin(s) from cloudflare/skills: cloudflare`). I have not checked the marketplace name on every Grok install, so please confirm the exact line against your own test.
