**Title:** README: name the MCP server, what it can change, and how to scope it

**Body:**

The README lists the two skills and "vendor-specific plugin manifests and MCP adapters" (lines 7 to 9). It does not say that the plugin connects to the hosted server at `https://mcp.supabase.com/mcp`, that the server's tools run SQL, manage migrations and deploy functions on hosted projects (as `SUPABASE.md` line 7 says for the Gemini extension), or how to limit it. Every adapter connects without `project_ref` or `read_only`, which is a sensible default for development, and Supabase's own MCP guide asks for both before a production project is connected.

For Grok Build users the scoped form already works without changing the plugin. With grok 1.0.44 in a clean Grok home, after `grok plugin install https://github.com/supabase-community/supabase-plugin.git@2c6d02d4565babe784103ee4d446a93ae9b24151 --trust`, a user-level entry with the same name replaces the plugin's server:

```toml
# ~/.grok/config.toml
[mcp_servers.supabase]
url = "https://mcp.supabase.com/mcp?project_ref=<project ref>&read_only=true"
```

`grok inspect --json` then lists `supabase` at the scoped URL with source `configToml`.

Suggested README section:

```markdown
## MCP server

Each plugin connects your agent to Supabase's hosted MCP server at
https://mcp.supabase.com/mcp and signs in with OAuth. Its tools can run SQL, apply
migrations, deploy Edge Functions and read logs on the projects your sign-in can reach.
Before you connect a production project, scope the server with `?project_ref=<ref>`
and `?read_only=true` as the MCP guide describes:
https://supabase.com/docs/guides/getting-started/mcp
```

A short install line per agent would help too; for Grok Build, `grok plugin install supabase@xai-official --trust` with the xAI marketplace registered, or `grok plugin install supabase-community/supabase-plugin --trust` without it (checked in a clean Grok home: `Installed 1 plugin(s) from supabase-community/supabase-plugin: supabase`). I have not checked the marketplace name on every Grok install, so please confirm the exact line against your own test.
