**Title:** Ship the full Apache-2.0 text in LICENSE, and list the MCP server in the README

**Body:**

Two small documentation fixes:

1. **LICENSE.** The file holds the 13-line Apache-2.0 notice (the "How to apply" boilerplate) rather than the license text, so GitHub's license detection reports `NOASSERTION` (`gh api repos/vercel/vercel-plugin --jq .license.spdx_id`), and tools that read that field cannot tell the plugin's license. The manifest, `package.json` and the README all say Apache-2.0. Suggested fix: replace `LICENSE` with the full text from https://www.apache.org/licenses/LICENSE-2.0.txt, and keep the copyright notice in a `NOTICE` file or at the top.

2. **MCP server.** The Components section (README.md line 38) covers the ecosystem graph, skills, agents, commands and hooks, but not the bundled MCP server. Only the `note` in `.mcp.json` says it connects to `https://mcp.vercel.com` with OAuth and is read-only. Suggested fix: a short "MCP server" entry under Components with the URL, the OAuth step and what it can do.
