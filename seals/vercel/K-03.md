**Title:** Grok Build: the three agents and four commands do not load (manifest lists files, Grok reads folders)

**Body:**

The README lists Grok Build as supported, and the plugin installs: with grok 1.0.44 in a clean Grok home, `grok plugin install https://github.com/vercel/vercel-plugin.git@2b7e8732ac22aafa8319459a881631dd5cff3878 --trust` installs `vercel v0.52.0`. But `grok inspect --json` lists none of the plugin's agents (`ai-architect`, `deployment-expert`, `performance-optimizer`) and none of its commands (`bootstrap`, `deploy`, `env`, `status`), while `grok plugin details vercel` prints `4 command dir(s), 3 agent dir(s)`.

The cause is the shape of `.claude-plugin/plugin.json` (lines 21 and 27): `commands` and `agents` list individual `.md` files. Claude Code accepts file paths there. Grok treats every entry in those fields as a folder: it joins each path to the plugin root (crates/codegen/xai-grok-agent/src/plugins/manifest.rs line 47 in xai-org/grok-build) and then lists it with `read_dir` (discovery.rs line 336 for agents, registry.rs line 453 for commands). A file is not a folder, so nothing is found.

The file lists look deliberate: they keep `commands/_conventions.md` and the `.md.tmpl` sources from loading. The `.tmpl` files are already safe in both harnesses, because only `.md` files load. So a fix that works for Claude Code and Grok alike:

1. Move `commands/_conventions.md` out of `commands/` (for example to `docs/command-conventions.md`), and update the two hints in `scripts/validate.ts` (lines 605 and 611) that point to it.
2. In `.claude-plugin/plugin.json`, replace the two file lists with the folders, `"commands": "./commands/"` and `"agents": "./agents/"`, or drop both fields so each harness uses its default folders.

A check that would catch it: install into a clean `GROK_HOME` and assert that `grok inspect --json` lists three agents and four commands from the plugin.

Until then, a Grok user can copy the files into `~/.grok/agents/` and `~/.grok/commands/`; in a clean Grok home that made all seven load.
