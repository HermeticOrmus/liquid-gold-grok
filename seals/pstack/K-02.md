**Body:**

A second reason to change the defaults: xAI's Grok marketplace lists pstack unmodified (see #446). At `2eb7ed4` the defaults in poteto-mode/SKILL.md line 93 and the rule shape in setup-pstack/SKILL.md line 39 name `grok-4.7-xhigh-fast`, `claude-opus-5-5-max` and `gpt-5.6-sol-max`. Those are Cursor slugs; nothing maps them for another harness.

pstack already defines `inherit-parent` as always valid ("the role runs on the parent chat model (omit Task `model`)", line 93). Making `inherit-parent` the default for every role, and treating named slugs as an opt-in that `/setup-pstack` writes after detecting what is available, would fix the unresolvable-slug failure this issue reports and let the same skills run in harnesses with other model names.
