**Title:** docs(api-documentation): back the AsyncAPI promise, fix a mislabelled fence

**Body:**

1. **AsyncAPI (K-05).** The plugin README promises "AsyncAPI 3.0: event-driven API documentation (Kafka, Pub/Sub, WebSocket)" (line 18) and lists AsyncAPI in the `api-documentation` skill's pattern library (line 10). None of the three skills mentions AsyncAPI (`grep -c -i asyncapi` returns 0 for each `SKILL.md`); it appears only as one line in `agents/api-doc-writer.md` (line 254) and one heading in `commands/api-docs.md` (line 64).

   Either add a short AsyncAPI 3.0 section to `skills/api-documentation/SKILL.md` (the document skeleton with `channels`, `operations` and `messages`, one Kafka binding example, and how message examples and error payloads are documented), or change the README lines to "OpenAPI first; AsyncAPI noted in the agent" so the promise matches what ships.

2. **Fence (K-06).** `skills/openapi-patterns/SKILL.md` line 27 fences a list of URL paths as `yaml`. It is not YAML (`yaml.safe_load_all` raises `expected '<document start>', but found '<scalar>'`), so editors highlight it wrong and a docs linter that parses YAML fences would fail on it. Change the fence to `text`.
