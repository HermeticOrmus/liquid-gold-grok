**Title:** Add a LICENSE file

**Body:**

`.grok-plugin/plugin.json` line 11 says `"license": "MIT"`. The repository has no license file at `879fae0`, and git history shows none was ever added. GitHub's license API returns 404, and the repository metadata has `license: null`. The README used to end with a License section whose entire text was the word MIT. Commit `6860457` ("docs: marketplace install steps, drop license section", 2026-07-21) removed that section, so the README at HEAD no longer states a license either.

Anyone redistributing the plugin, and catalogs that record the license of a pinned commit, can only see the JSON field. If MIT is the grant you intend, please add the MIT license text as `LICENSE` at the repository root, with your copyright line, and point the README at that file. If the plugin is not under MIT, please change or remove the manifest field so the file and the field agree.
