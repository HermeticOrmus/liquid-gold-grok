**Title:** Add a LICENSE file (AGPL-3.0)

**Body:**

The plugin states its license twice: `"license": "AGPL-3.0"` in `.grok-plugin/plugin.json` (line 11) and "This plugin is licensed under AGPL-3.0" in the README (line 137). The repository has no license file, so GitHub reports no license for it (`gh api repos/firecrawl/firecrawl-grok-plugin/license` returns `Not Found (HTTP 404)`), and tools that read the license from the repository, including GitHub's own license detection, see the plugin as unlicensed.

Proposed change: add the unmodified AGPL-3.0 text as `LICENSE` at the repository root, the same file the main Firecrawl repository uses. No other change is needed; the manifest and README already say AGPL-3.0.
