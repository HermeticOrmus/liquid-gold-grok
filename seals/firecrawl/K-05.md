**Title:** README and skill copy: Grok install line, current names, one CLI setup path

**Body:**

Three copy fixes, checked with grok 1.0.44 in a clean Grok home.

**1. Install line (README lines 25 and 29).** The README says to run `/plugin` and search, and to check the connection with `/mcp`. Grok's command reference lists `/plugins`, `/marketplace` and `/mcps`. In a home without xAI's marketplace registered, the name alone does not install:

```text
$ grok plugin install firecrawl --trust
Error: No marketplace plugin named "firecrawl" in any registered marketplace.
```

xAI's listing also pins `7100b62` (1.2.0), so a user who finds the plugin there does not get Alexandria. The direct form installs cleanly (on 2026-10-01 the head of `main` is `fc26fcf`, the commit checked here):

```bash
grok plugin install https://github.com/firecrawl/firecrawl-grok-plugin.git --trust
```

Suggested: give that line, and `/mcps` for the connection check.

**2. Names that drifted.**

- `skills/firecrawl-cli/rules/install.md` line 20 lists 10 skills "listed in its manifest (`.grok-plugin/plugin.json`)". The manifest has no skills list, and the plugin ships 12 (`firecrawl-developer-search` and `firecrawl-alexandria` are missing).
- `skills/firecrawl-cli/SKILL.md` lines 55, 263 and 264 say the `firecrawl-build` and `firecrawl-workflows` skills are "already installed alongside this CLI skill". The plugin does not ship them; `install.md` line 20 says so.
- `firecrawl_extract` is named in the README (line 35), the `.mcp.json` note and `firecrawl-cli` (lines 14 and 45). With an API key header the server lists 27 tools, and `firecrawl_extract` is not one of them.
- `commands/skill-gen.md` (lines 14 to 26) uses only `firecrawl map`, `scrape` and `crawl` CLI commands, while the README makes the hosted server the default path. Naming the MCP tools first would let the command work without the CLI.

**3. One CLI setup path.** The README's CLI step is `npm install -g firecrawl-cli` and `firecrawl login --browser` (line 37). `rules/install.md` recommends `npx -y firecrawl-cli@1.16.2 init -y --browser` (line 15), which also "installs core, build, and workflow skills" across all detected coding editors (lines 18 and 30), with `-y` skipping the prompt. Suggested: pick one path for the plugin, and if it is `init`, say in the README that it installs skills into other agents on the machine.
