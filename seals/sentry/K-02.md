**Title:** Grok plugin README: describe the current skill library and the onboarding updates

**Body:**

The Grok plugin installs and loads cleanly. With grok 1.0.44 in a clean Grok home, `grok plugin install https://github.com/getsentry/plugin-grok.git@3d0347fbc4f2bfd39a30c9a2107f52f3efc54d67 --trust` installs `sentry v1.4.1`, and `grok inspect --json` lists all 8 skills and the `sentry` MCP server.

Two parts of `src/plugins/grok/README.md` describe the library as it was before #283 and #311:

1. Line 4 promises "code review with Sentry context" and line 23 "debugging and code-review workflows". #283 removed `sentry-code-review` and `sentry-pr-code-review`, and none of the 8 skills at this commit reviews code. `src/SKILL_TREE.md` line 13 also offers "Review code: Resolve Sentry bot comments or check for predicted bugs" with no skill behind it.
2. Lines 28 and 29 say "A few router skills are always available; the rest are hidden behind them with `disable-model-invocation`". #311 retired the routers; at this commit no skill sets `disable-model-invocation`, and all 8 load for the model.

A third point the README could cover: `sentry-get-started` makes onboarding progress calls through the MCP server, without narration, when the first prompt carries an onboarding code (`SKILL.md` lines 23 to 94). The rules there keep the payload to stage statuses and a short note, which is good; a README line would let a user know the updates exist before they paste an onboarding prompt.

Suggested change to `src/plugins/grok/README.md`:

```markdown
It teaches Grok how to use Sentry: getting started and SDK instrumentation for any
platform, production issue debugging via the Sentry MCP server, readable stack traces,
releases, alerts, OpenTelemetry routing, and Apple snapshot testing.

## What's included

- Eight skills: sentry-get-started, sentry-instrument, sentry-debug-issue,
  sentry-fix-stack-traces, sentry-setup-releases, sentry-create-alert,
  sentry-otel-exporter-setup, sentry-snapshots-cocoa.
- The hosted Sentry MCP server for querying your Sentry environment.

When you start from an onboarding prompt in the Sentry web app, sentry-get-started
reports each setup stage back to that page through the MCP server.
```

and drop the "Review code" option from `src/SKILL_TREE.md`, or point it at a skill that exists.
