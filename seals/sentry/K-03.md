**Title:** Skill frontmatter says Apache-2.0; the repository license is MIT

**Body:**

Every skill in `src/skills/` declares `license: Apache-2.0` in its frontmatter (line 4 of each `SKILL.md`). The repository's `LICENSE` is MIT ("Copyright (c) 2025 Sentry (https://sentry.io) and contributors"), GitHub reports the repository as MIT, and the generated Grok plugin carries the same MIT `LICENSE` with `"license": "MIT"` in `.grok-plugin/plugin.json`.

Someone redistributing a single skill reads Apache-2.0; someone reading the repository reads MIT. If the skills are MIT like the rest of the repository, the frontmatter can say `license: MIT`. If they are meant to be Apache-2.0, an Apache-2.0 license file next to them (and a note in the README) would make that clear.
