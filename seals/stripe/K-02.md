**Title:** README: the Grok Build install line needs a marketplace

**Body:**

The README's Grok Build section (line 55) says `grok plugin install stripe --trust`. With grok 1.0.44 in a Grok home that has no marketplace registered, that fails:

```text
Error: No marketplace plugin named "stripe" in any registered marketplace.
```

The plugin itself installs cleanly by URL (checked at this commit):

```bash
grok plugin install https://github.com/stripe/ai.git@9a36da0458aafcfcc6be3094cf9ef2880fa4226b#providers/grok/plugin --trust
```

Suggested fix: show that direct form, or the qualified form `stripe@xai-official` with the step that registers xAI's marketplace, so the line works on a fresh install.

Evidence:
- https://github.com/stripe/ai/blob/9a36da0458aafcfcc6be3094cf9ef2880fa4226b/README.md#L55
